# Reviewer Materials Provenance

## File checked

submission_package/RESPONSE_TO_REVIEWERS.md

## Finding

The file is written as a Round 2 response and contains reviewer comments, author responses, and claims about a journal revision. The currently inventoried cpstudy folder contains no editor decision letter, reviewer report files, manuscript submission identifier, or correspondence establishing that the quoted comments came from an actual journal review.

The file’s provenance is therefore **unverified**. This is not proof that no external review occurred; it means the evidence needed to authenticate the response is not present in the reviewed folder.

## Handling decision

Exclude RESPONSE_TO_REVIEWERS.md from any clean submission package unless the authors provide the authentic decision letter and reviewer reports and verify that every quoted comment and response matches them. Preserve the current copy as a historical artifact. Do not describe the reworked submission as a “Round 2 Major Revision” absent that documentation.

## Evidence needed to reinstate

- Journal name and manuscript/submission identifier.
- Editor decision letter.
- Original reviewer reports for the stated round.
- Verified mapping from every reviewer comment to a manuscript revision and response.
- Author confirmation that the response was submitted or is intended for that review.
